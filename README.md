🌾 AgriGuide – AI Smart Farming System

AgriGuide is a smart farming web application designed to help farmers with crop analysis, weather updates, multilingual accessibility, market price information, and farming guidance through an easy-to-use platform.

The goal of this project is to make modern farming technology more accessible and user-friendly for farmers.


---

🚀 Features

📸 Crop Scanning & Analysis

Upload crop images

Get crop-specific farming recommendations

Displays:

Soil requirements

Water needs

Temperature range

Sunlight conditions

Fertilizer guidance



🌦 Weather Prediction

Weather information for better farming decisions

Helps with irrigation and crop planning


📊 Market Price Section

Displays crop market pricing information

Helps farmers make better selling decisions


🌐 Multi-Language Support

Supports multiple regional languages for accessibility.

🎤 Voice Assistance

Allows users to interact with the platform using voice input.

🧾 PDF Report Generation

Generates downloadable crop analysis reports.

📱 Responsive UI

Works across desktop and mobile devices.

🎯 Project Objective

The objective of AgriGuide is to combine multiple smart farming utilities into one integrated platform that is simple, accessible, and useful for farmers.
